## class(클래스)
- 실제 대상(객체)를 코드로 표현
- 대상객체로 표현한 것이 클래스
- 객체로 만들기 위한 틀(붕어빵틀)
- 재료에 따라서 다양한 객체
- 변수와 메서드를 가지고있음
- 클래스를 가지고 생성을 한것을 객체/인스턴스

- 상태: 특징 -> 변수, 동작:메서드(할 수 있는일)
- 상태나 기능 바뀐다면?-> 쉽게 수정 가능함.

## 클래스 구성요소
- 1.필드(field)
- 2.메서드(method)
- 3.생성자(constructor)

## 접근 제어자
- 1.private : 외부에서 접근을 차단, 클래스 내부에서만 접근이 가능
- 2.protected: 나를 상속받은 클래스 까지 접근가능
- 3.<default>: 같은 패키지내에있으면 접근가능
- 4.public: 누가나 외부애서 접근가능
